# Ocular LLM Explainability

This repository provides methods to use LLMs to generate explanations for RETFound diagnoses on retinal fundus images.

## Features
- Transformer-Explanability to generate saliency maps
- Updated RETFound with LRP
- Methods to use LLMs to generate explanations for RETFound diagnoses

## Installation
Clone the repository and install the dependencies:
```bash
git clone https://github.com/YatingPan/ocular-llm-explainability.git
cd ocular-llm-explainability
pip install -r requirements.txt
```
